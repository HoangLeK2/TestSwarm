# Documentation Archive

Status: historical
Last audited: 2026-05-18

Archived docs are preserved for context but are not implementation contracts.

Use current docs instead:

- Product requirements: `docs/product/prd.md`
- Module behavior: `docs/modules/*`
- API surfaces: `docs/api/route-matrix.md`
- Data schema ownership: `docs/data/schema.md`

Archive buckets:

- `legacy-specs/`: old DF ticket specs consolidated into module docs.
- `external-prd/`: research PRDs for external tools and reference products.
- `research/`: research reports and mapping notes.
- `plans/`: historical implementation plans and phase notes.
- `historical/`: changelogs, old reports, and rollout history.
