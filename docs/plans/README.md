# Active Plans

Status: active
Last audited: 2026-05-19

This directory tracks implementation gaps and follow-up plans that are not yet
module contracts. Use these files when assigning work to agents or developers.

Rules:

- Keep product intent in `docs/product/`.
- Keep durable implementation contracts in `docs/modules/`.
- Keep active gap/action tracking here.
- Keep historical plans in `docs/archive/plans/`.
- When a gap is resolved, update the relevant module/profile docs and either
  remove the gap or mark it done with the resolving change.
